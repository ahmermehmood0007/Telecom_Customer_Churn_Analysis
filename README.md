# Telecom Customer Churn Analysis

## Project Overview

This project focuses on analyzing telecom customer churn data using SQL and PostgreSQL.

The main objective of the project is to identify:
- customer churn behavior
- risky customer segments
- revenue loss
- retention insights
- business KPIs

The project follows a real-world data analyst workflow including:
- data cleaning
- exploratory data analysis
- KPI analysis
- business insights
- churn analysis



## Tools Used

- PostgreSQL
- SQL
- Excel / CSV Dataset
- Git
- GitHub



## Dataset Information

The dataset contains:
- customer demographics
- contract types
- payment methods
- internet services
- monthly charges
- total charges
- tenure
- churn status

Dataset Size:
- 7000+ customer records

## Key Business Insights

- Month-to-month contracts showed highest churn.
- Electronic check payment method had high churn rate.
- Customers with low tenure churned more.
- High monthly charges increased churn risk.
- Senior citizens showed higher churn percentage.
- Long-term contracts improved retention.
